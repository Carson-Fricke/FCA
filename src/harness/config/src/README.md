# src

Strict harness configuration loading, normalization, and canonical hashing. data.options maps configured input aliases to validated shared lake selectors. Provider access and contract resolution occur during replay acquisition, never configuration parsing.

- `lib.rs` — Authoritative harness document syntax, replay schema, and typed normalization.
- `loader.rs` — Safe configuration loading and runtime secret resolution.
- `models.rs` — Strict typed configuration models.
- `replay.rs` — Authoritative replay document validation. Compact shipped documents use explicit defaults.
- `yaml.rs` — Deterministic YAML-subset parser.
