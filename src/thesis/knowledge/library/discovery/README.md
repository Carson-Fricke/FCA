# Discovery method cards

These searchable knowledge pages teach representation and investigation choices.
They are reference material, not workflow authority or executable implementations.
The SDK remains authoritative for callable signatures and numerical conventions.

- `executable-discovery-tool-bag.md` maps supported kernels to limitations and
  supplies composition, persisted-output, and frozen-fitting recipes.
- `discovery-study-design.md` organizes investigations around an evolving sketch.
- `directional-change-events.md` explains confirmation, event clocks, and thresholds.
- `perceptually-important-points.md` explains trailing shape compression and timing.
- `volume-and-volatility-conditions.md` describes activity/range conditioning.
- `trade-prices-versus-midquotes.md` distinguishes transaction and quote effects.
- `time-of-day-breakdown.md` describes intraday schedule conditioning.
- `stability-across-periods.md` describes persistence across development periods.
- `simple-lead-lag.md` describes lagged relationships and causal alignment.
- `signal-size-buckets.md` describes response by signal magnitude.
- `return-continuation-and-reversal.md` describes competing directional mechanisms.
- `market-adjusted-returns.md` describes common-market controls.
- `cost-and-delay-sensitivity.md` describes economic feasibility and execution delay.
