# thesis/application

FCA composition roots, prompts, launcher and domain-facing projections. This is where providers, persistence, policies and concrete extensions are selected.

- `__init__.py`: application capability package.
- `composition.py`: Compose chat, conversations, and workflow services for local and deployed HTTP; select model-family adapters from configured model identities for root, child, and workflow model calls.
- `development.py`: Research workflow launch and outcome contracts.
- `job_classification.py`: Classifies FCA harness executions for application and HTTP presentation outside neutral runtime records.
- `prompts.py`: FCA root-agent policy: launch directly from the preserved idea; discovery owns research setup.
- `workflow_launcher.py`: Launch registered workflows asynchronously from trusted context; compose the research child registration beside hypothesis development.
- `workflows.py`: Compose model/execution ports, hypothesis services and bounded research-investigation services with parent exposure recording.
