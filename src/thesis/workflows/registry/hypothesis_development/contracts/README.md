# Hypothesis-development completion contracts

These records validate accepted phase handoffs and rebuild their durable state.
They carry scientific interpretation and job references; harness jobs remain the
execution and financial-metric authority. Contracts do not dispatch tools, own
operator interaction or schedule phase agents.

| File | Purpose |
| --- | --- |
| `__init__.py` | Public handoff records and schemas. |
| `creation.py` | Trusted launch identity, explicit frozen partition and dependency recovery. |
| `discovery.py` | Candidate-thesis discovery and honest no-candidate outcomes. |
| `hypothesis.py` | Selected hypothesis and falsification model references. |
| `plan.py` | Declared trial plan. |
| `trials.py` | Trial completion records and result references. |
| `evidence.py` | Research evidence envelopes. |
| `verdict.py` | Scientific verdict interpretation. |
| `strategy.py` | Strategy references and terminal strategy backtest handoffs. |
| `candidates.py` | Parameter search assignments, states and shortlisted candidates. |
| `nulls.py` | Supported permutation methods, signal-dependency assertions and conditional tail evidence. |
| `variation.py` | Deterministic marginal and declared joint-parameter experiments. |
| `forward.py` | Matched forward null and variation evidence using the same contract semantics. |
| `rca.py` | Root-cause interpretation and revision direction. |
| `validation.py` | Shared handoff validation errors. |

Null methods are explicit: ordinary permutation destroys serial ordering;
nontrivial block permutation destroys ordering between blocks while retaining
dependence inside each block. Neither claims to preserve a calendar volatility
schedule or cross-symbol dependence. Supported claims are validated against the
method; strategy-specific adequacy limitations remain scientific interpretation.
Tail evidence is selection-conditional, not search-adjusted. Failed or unresolved
replicates contribute conservatively to the p-value numerator and denominator.
Declared target resolution determines the minimum finite seed-plan length, with
no universal replicate ceiling.

Variation declares `one_at_a_time` or `joint`, with explicit interaction groups.
All vectors and groups freeze into the forward design. Uncovered interactions,
missing metrics, undefined statistics and execution failures remain visible.
