# Hypothesis development

The phase doctrine composes creative discovery, assumption falsification,
strategy design, candidate selection, explicit null experiments, deterministic
parameter variation and frozen forward evaluation. Contracts carry scientific
assessments; provenance verifies their jobs against immutable harness inputs
and results. Exposure is retained before dispatch in the execution ledger.
`design.py` freezes forward commitments. `artifacts.py` projects accepted tables
for development and forward reports. Deployment remains a separate workflow.

Discovery organizes research around a versioned strategy sketch in workspace Git.
Its completion carries only `sketchReference`, investigation/job references and
scientific limitations. Model creation prepares an executable falsification study
against that exact revision, with `assumptionTests` connecting sketch assumptions
to registered falsifiers. Trials verify the reference and component attribution;
verdict assesses every assumption, preserving untested and inconclusive states.
Strategy construction resolves the same accepted sketch rather than inferring a
new premise from unrelated studies. Knowledge retrieval teaches and navigates the
executable tool bag; prior study findings challenge an independently drafted sketch.
