# Product presentation demonstrations

Synthetic local examples exercise product components without submitting jobs.

- `backtest/`: backtest report presentation.
- `chat-tools/`: Activity rail and compact strategy sketch using the real chat
  transcript and tool renderers.
- `research/`: nine SDK-generated research compositions in inline study cards.
- `study-result/`: shared production study surface with lifecycle scenarios, nine SDK compositions,
  captured data and explicit bounded-preview behavior.
- `spy0dte/`: options research presentation.
- `spy0dte-clusters/`: clustered options research presentation.
