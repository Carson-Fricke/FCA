# Shared study result demonstration

`/demo/study-result` uses the production `StudyToolCard` and research components.
It submits no jobs. Injected artifact and status readers provide local scenarios.

- `+page.svelte`: route entry and document title.
- `StudyResultDemo.svelte`: conversation wrapper, nine validated SDK examples,
  captured data, a 5,100-row bounded-preview example, and lifecycle controls.
- `snapshot.ts`: captured 13 display-rounded observations and 41 exact metric
  strings from the linked MSFT study; no invented research descriptors.

Dataset semantics and the nine family publications are generated by the real SDK.
The large preview is a local synthetic paging example; it demonstrates the same
5,000-row loading budget used in chat. Run completion changes the status reader
while retaining the mounted card. Exports include complete example evidence.
