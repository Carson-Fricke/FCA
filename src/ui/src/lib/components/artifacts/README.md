# Committed artifact presentation

These components render backend-produced workspace artifact projections. They
do not execute programs, reconstruct evidence or select accepted revisions.

- `ArtifactCard.svelte` renders gallery identity and provenance.
- `ArtifactDetail.svelte` composes previews, history and files.
- `ArtifactKindBadge.svelte` identifies strategies, studies, indicators and sketches.
- `ArtifactTree.svelte` groups artifacts and their readable files.
- `FileViewer.svelte` reads bounded committed file content.
- `HistoryTimeline.svelte` displays committed revision history.
- `IndicatorArtifactPreview.svelte` shows inputs and consuming program references.
- `IngestChips.svelte` displays declared market inputs.
- `SketchArtifactPreview.svelte` renders the research argument, representation
  dependencies, assumptions, component identities and job evidence links.
- `StrategyArtifactPreview.svelte` displays execution design and limitations.
- `StudyArtifactPreview.svelte` displays study windows, dependencies and metrics.
