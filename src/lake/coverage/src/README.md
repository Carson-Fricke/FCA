# Coverage application

Session coverage and ensure planning over catalog ports. Options and equities share XNYS sessions; option bars retain their interval in coverage identity. This slice does not fetch market data.

- `application.rs`: provider-independent coverage and ensure use cases.
- `error.rs`: coverage application rejection contract.
- `lib.rs`: intentional capability exports.
- `service.rs`: calendar-aware coverage and gap planning, including trade revisions for derived bars.
- `selection.rs`: shared option membership, coverage and canonical file classification for native and HTTP callers.
